# Bibliography inventory and incident survey, 2026-09-26

Owner direction: "scour this machine, esp /casa/ for bib/ris files in projects that might not have been generated by / for zotero, and clean things up. also use cass-search ... to search transcripts from sessions doing the kind of work that should be formalized." Home was included at the owner's word, as was `~/Downloads`, with the caution not to treat every PDF there as an import. This page records what was found, read-only, and the decisions it raises. It decides nothing.

## Method

A find over `/Volumes/Casa` and the home directory for `.bib`, `.ris`, `.enl`, `.enw`, `.nbib`, `.bibtex`, `.biblatex` and `.csl.json`, skipping caches, virtual environments, checkouts, the refs corpus scratch and the refs repository itself. Each file was fingerprinted for origin (Better BibTeX keys and headers, JabRef and Mendeley comments, Zotero mentions) and its entries compared against the live catalog, read-only, by DOI, by normalized title and by citation key, using refs's own BibTeX adapter for `.bib` and a minimal tag reader for `.ris`. The transcript search used cass over all indexed agents with eight hybrid queries (BibTeX and citation keys, DOI lookup, Zotero and Better BibTeX, pandoc and citeproc, adding references, RIS import, finding a paper to cite, reference-list formatting), then grep over the exported sessions the hits pointed at. Nothing was changed anywhere.

## Decisions raised

- **A. Import the agent-written paper bibliographies**, about 115 entries of which 95 are new, one batch per project with a project created and cited, so each paper's bibliography can later be an export. Recommendation: yes.
- **B. The RIS files**, 43 class-era entries and 56 in Downloads. Refs has no RIS route. Add a small adapter, since RIS is a flat tag format and is what databases hand out, or leave the files as archives. Recommendation: the route, because two of the six files hold things the catalog lacks.
- **C. The owner's own works** in `pub/cv/refs`: into refs as a kind or collection with CV sections as projects, or left as the CV's own data. No recommendation.
- **D. Features the transcripts justify**, each now with incidents behind it: lookup by DOI on add and a verify pass against Crossref; export profiles per consumer. Their own briefs after the docs pass.
- **E. The carried-over Downloads folder** `_from2020mbp`, 42 GB, six top-level folders, 3,393 PDFs mostly under a books folder and DEVONthink exports: move it out of Downloads as one unit. Nothing in it needs sorting first; its bibliographic files are covered above.

Nothing in the inventory needs a file touched in place. Every project bibliography is part of a build and stays where it is; the clean-up refs offers runs the other way, the catalog learning everything ever cited.
