# Independent Bibliographic Revision Review, 2026-09-21

## Verdict

The selected model is substantially clearer and fits the nine recorded decisions. The revised design is not yet ready for an immediately executable slice 1 task list. Repair the bounded validator, a small set of missing routes, and the registry's export rules first. The pending constitution amendment is a separate known prerequisite; this review does not approve it.

Reviewed `docs/bibliographic-model.md`, the specification, data model, plan, records/bibliography/interchange contracts, the JSON registry, quickstart, and the 14-case probe source/results plus standard-render results. This was source-based review; no live private catalog, bibliography or PDF was read, no probe was rerun, and no governing document was edited. The reviewer previously authored the semantic-row review but did not author these revisions or the bibliography checklist. Checklist markers assess written requirements, not implementation success.

## Positive evidence and limits

The model eliminates the competing editable publisher/genre/number namespaces. Agent input is now an explicit third route. The standard rendering result is useful: native @standard changes citation authorship while portable @misc retains the supplied corporate author and year. The probe correctly reports its incomplete importer/schema coverage and normalizes the differential oracle's title casing without changing storage policy. It does not prove all registry rows or every extension.

The closed loss codes, unknown override, waiver bindings, deliberate-clear precedence, portable default, terms instead of offsets, notes-as-context scope, external originals archive and slice 1 restore obligation are substantive improvements. No new broad research pass is needed to resolve BR01–BR11. Most are small schema/contract completions; BR06 needs faithful interpretation of the accepted key rule or a deliberately recorded change.

### Nonblocking implementation cautions

Some broad input row scopes intersect narrower canonical applicability (for example Zotero publisher on webpage/standard and pages on report). The new admission rule gives a deterministic preserved-only/unassessed result, so this is no longer an ambiguous validator. Tighten row scopes or record those exclusions explicitly when packaging the registry so a reader does not mistake every listed source scope for a promoted editable path. Do not widen type applicability merely to make a structural join report zero differences.

The complete schema, tests for all promoted mappings, title protection, role rendering and full-date consumer behavior are future implementation obligations. Their absence from the current prototype does not itself prevent task generation. The constitutional decision remains outside this review's authority. BR08's stale sentence is now fixed; this review has no remaining material bibliography blocker to task generation for the declared slice.
