# refs: Product Vision

**2026-09-21.** This charter owns product intent; the [slice 1 specification](../specs/001-academic-catalog/spec.md) bounds current delivery. The [earlier charter](archive/vision-pre-trim.md) preserves research context. Broader aspirations below do not add slice 1 tasks.

## Purpose and user

refs is a personal, searchable source catalog for material worth finding, using or citing again. Save casually, recover useful material, select it for a purpose, and cite rigorously. Initial use is a researcher/instructor working with Quarto, external PDFs, Markdown notes and research agents.

References and corrections gathered by agents currently remain scattered among manuscript bibliographies. The first useful tool retains that work, accepts supplied metadata and incomplete records, finds it again, links or copies attachments, and explicitly exports a paper's citations. Saving is a completed action: tags, projects, reading status and polished metadata are optional, not an inbox to clear.

## Enduring boundaries

SQLite owns stable catalog identities, assigned keys, accepted metadata and relationships. Original input, explicit human corrections, personal context and generated claims remain distinguishable. Complete metadata does not prove full-text reading, credibility or support for a claim. Similar titles do not establish identical sources or editions.

External PDFs and authored notes stay under their owners' control. Linking/removing catalog relationships does not rename/delete them or rewrite prose. Managed status comes from a recorded path beneath the configured library root. Intake is explicit; slice 1 copies and retains the original. Its owner-selected filename convention applies to new copies unless keep-name is chosen. Collection edits never move files; later reorganize is explicit and preserves names.

Projects reuse sources without duplicating their identity. Slice 1 projects contain only cited sources; background membership is a later option. Bibliographies are reproducible standalone artifacts written only by explicit export, including deliberate automation calls. Catalog changes never regenerate them automatically. Missing facts and lossy mappings are disclosed without invention.

The CLI serves both people and agents with structured input/output, visible settings, revisions, actionable failures and bounded effects. Everyday academic work requires no model service or credentials. A recoverable library includes preserved originals and a backup actually restored to a separate home; an inventory of links is not a backup of the files.

## Broader direction, not current scope

Over time, useful sources may include web captures, PDFs and linked notes, with retrieval by exact identity, words or meaning. Results should identify the representation and completeness behind each passage. An external agent supplies the research/teaching purpose and evaluates how retrieved evidence serves it; refs need not become an autonomous researcher or note editor.

Future controlled classification may use approved hierarchical concepts, preserving human corrections and separating assignment from vocabulary changes. Imported keywords do not silently become approved tags. Abstention is valid; model scores are not verified evidence. Web extraction should retain honest content status, never mistake a login page for the intended article.

Search, extraction and enrichment sit behind application-owned boundaries. Selectable implementations and an independent replacement demonstration become required when a second implementation is evaluated, under constitution 2.0.0. QMD/Jev investigations remain bounded future evaluations, not prerequisites for the first paper. Interfaces serve demonstrated variation rather than speculative frameworks.

Full Zotero migration, richer interchange, collection-based organization and broader recovery/exit tools remain future decisions. No integrated reader/annotation editor, word-processor plugin, multi-user hosting or unrestricted vault synchronization is implied. The owner must use slice 1 on a real paper before slice 2 specification work.

## Success and design discipline

The tool succeeds when saving and recovering references is easy, citations retain their meaning through the user's actual consumers, external files remain safe, and the catalog can be restored. Representative failure/fidelity checks matter more than successful parsing or architectural claims. The owner judges usefulness and weight.

Aim for good, professionally built and packaged software at 5 on the owner's scale. A metered 6 is acceptable for cheap-now/hard-to-retrofit seams; surface waits for a demonstrated need. [Right-sizing](right-sizing.md) defines the preservation floor and checkpoints. [Accepted decisions](behavior-decisions.md) own conventions; specifications own outcomes; plans/contracts label implementation choices; research records evidence and limits.
